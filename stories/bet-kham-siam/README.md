# เดิมพันข้ามสยาม: ร่างผู้ไร้นาม

โปรเจกต์เรื่องแต่ง 10 ตอน แนวผจญภัย สืบสวน และเหนือธรรมชาติ ฉากหลังสยามปลายสมัย ร.5

- `story/full-story.md` — บทต้นฉบับทั้งเรื่องและข้อมูลความต่อเนื่อง
- `story/overview.md` — ข้อมูลโลกและตัวละคร
- `story/episodes/` — บทแยกแต่ละตอน (สำเนาจากบทต้นฉบับ โปรดปรับให้สอดคล้องกัน)
- `production/google-flow/ep01-storyboard-studio.json` — ไฟล์ส่งออก Storyboard Studio ต้นฉบับ (Git LFS)

แก้วคือผู้ชนะ: รางวัลเงิน 100,000 บาทและรูปปั้นม้าทองคำขนาด 50 × 20 ซม. บทเป็นฉบับร่างและยังไม่ได้วัดความยาวเสียง

ไฟล์ JSON ขนาดใหญ่เก็บด้วย Git LFS ต้องติดตั้ง Git LFS และดึงไฟล์ LFS ให้ครบหลัง clone ก่อนนำไปลองนำเข้า Storyboard Studio ความสามารถนำเข้าขึ้นกับเครื่องมือ

> ไฟล์ Storyboard ขนาดใหญ่ยังอยู่ในเครื่อง รออัปโหลดด้วย Git LFS
